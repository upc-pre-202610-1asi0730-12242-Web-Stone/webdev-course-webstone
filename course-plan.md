# Fundamentos de Desarrollo Web

## Resumen del Curso

Este curso de 1 hora introduce a estudiantes de secundaria a la creación de
sitios web sencillos con HTML y CSS. **¡No requiere descargas!**
Solo abre tu navegador web.

**Duración total:** ~60 minutos  
**Público objetivo:** Estudiantes de 12 a 17 años sin experiencia en programación  
**Prerrequisitos:** Ninguno  
**Herramientas necesarias:** Solo tu navegador web (Chrome, Firefox, Safari, Edge)  
**Repositorio de código fuente:** [https://github.com/upc-pre-202610-1asi0730-12242-Web-Stone/webdev-course-webstone/tree/main](https://github.com/upc-pre-202610-1asi0730-12242-Web-Stone/webdev-course-webstone/tree/main)

## Secuencia de lecciones

### Lección 1: ¿Qué es el desarrollo web? (5 minutos)

- **Descripción:** Aprende qué hay detrás de cada página web y por qué HTML y CSS son los componentes básicos.
- **Enlace:** [Ver la lección](https://youtu.be/mScf_D-aNL0)
- **Consejos clave:** Sitios web = Contenido (HTML) + Estilo (CSS).
- **Empieza a programar:** [Abrir en CodePen](https://codepen.io/Fabian-Sandoval-the-sans/pen/pvRRWLJ)

### Lección 2: Introducción a HTML (10 minutos)

- **Descripción:** Explora las etiquetas HTML básicas y crea tu primera página.
- **Enlace:** [Ver la lección](https://youtu.be/wLCo3GU9oj0)
- **Consejos clave:** Usa `<html>`, `<head>`, `<body>`, `<h1>`, `<p>`.
- **Práctica:** [Abrir en CodePen](https://codepen.io/Checa21/pen/ByppdBW)

### Lección 3: Añadir más elementos HTML (8 minutos)

- **Descripción:** Agrega listas, imágenes y enlaces para que tu página sea interactiva.
- **Enlace:** [Ver la lección](https://youtu.be/neMTcQ-OY_A)
- **Consejos clave:** Usa las etiquetas `<ul>`, `<img>`, `<a>`.
- **Práctica:** [Abrir en JSFiddle](https://jsfiddle.net/c4fbp6h1/6/)

### Lección 4: Introducción a CSS (12 minutos)

- **Descripción:** Dale estilo a tu HTML con colores, fuentes y diseños.
- **Enlace:** [Ver la lección](https://youtu.be/cxrwXt_pACo)
- **Consejos clave:** Usa selectores como `body { background-color: blue; }`.

### Lección 5: Crear una página web sencilla (15 minutos)

- **Descripción:** Combina HTML y CSS para crear una página de perfil personal.
- **Enlace:** [Ver la lección](https://youtu.be/t-x5R-V7_Tc)
- **Consejos clave:** Aplica estilos y corrige errores paso a paso.
- **Proyecto final:** [Abrir en CodePen]([codepen.io](https://codepen.io/Fabian-Sandoval-the-sans/pen/zxNNPEj)

### Lección 6: Consejos y próximos pasos (10 minutos)

- **Descripción:** Mejores prácticas, errores comunes y dónde aprender más.
- **Enlace:** [Ver la lección](https://www.youtube.com/watch?v=FU9p2p4ANAs)
- **Consejos clave:** Valida tu código y explora la documentación de MDN.
- **Comparte tu trabajo:** [Envía tu creación](https://codepen.io/Fabian-Sandoval-the-sans/pen/vEggWLb)
