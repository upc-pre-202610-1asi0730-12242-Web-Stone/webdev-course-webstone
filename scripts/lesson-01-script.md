## [0:00 – 0:30] Introducción

> "Hola, bienvenidos. Hoy vas a aprender qué hay detrás de cada página web que ves en internet. Solo necesitas tu navegador — nada más."

## [0:30 – 2:00] ¿Qué es un sitio web?

_(Mostrar diapositiva: imagen de un sitio web)_

>"Un sitio web es un espacio en internet que tiene páginas web. Esas páginas están conectadas entre sí a través del World Wide Web, el famoso 'www' que ves en toda dirección de internet."
>"Dentro de esas páginas puedes encontrar texto, imágenes, videos, audio y gráficos."

_(Mostrar diapositiva: HTML a la izquierda, CSS a la derecha)_

>"¿Y cómo se construye todo eso? Con dos cosas: HTML y CSS."
>"El HTML es el esqueleto de la página. Es solo texto con etiquetas especiales que le dicen al navegador qué es cada cosa. Sin HTML, no hay página."
>"El CSS es la decoración. Le dice al navegador cómo se tiene que ver cada cosa — colores, tamaños, dónde va cada elemento. Sin CSS, la página existe pero se ve aburrida."

## [2:00 – 4:00] Demostración en CodePen

_(Abrir CodePen en pantalla — codepen.io/pen)_

>"Ahora lo vemos en vivo. Entra a codepen.io, haz clic en 'Pen' y ya puedes escribir — sin crear cuenta."
>"Mira, tiene tres secciones: HTML, CSS y el resultado. Lo que escribas aquí arriba aparece aquí abajo al instante."

_(Escribir en la sección HTML de CodePen)_

>"Voy a escribir esto:"

```html
<h1>Hola, mundo</h1>
<p>Esto es mi primera página web.</p>
```

>"¿Ves? Ya apareció abajo. Eso es HTML — le dije al navegador que esto es un título y esto es un párrafo."

_(Escribir en la sección CSS de CodePen)_

>"Ahora le agrego color con CSS:"

```css
h1 {
  color: blue;
}
```

>"El título cambió de color. Eso es CSS — le cambié el estilo sin tocar el HTML."
