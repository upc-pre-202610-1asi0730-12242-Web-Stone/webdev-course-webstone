# Fundamentos de Desarrollo Web — WebStone

Curso introductorio de desarrollo web para estudiantes de secundaria (12–17 años).
Cubre los fundamentos de HTML y CSS en 6 lecciones cortas en video.
No requiere instalar nada — solo un navegador web.

## ¿Cómo usar este repositorio?

### Para ver el curso
Dirígete al archivo `course-plan.md` y sigue los enlaces de cada lección.

### Para practicar
Cada lección tiene un enlace directo a CodePen en el `course-plan.md`.
No necesitas crear una cuenta — solo abre el enlace y empieza a escribir.

### Para ver el código completo
Revisa la carpeta `completed-examples/` de la lección correspondiente.

### Para ver el código inicial de práctica
Revisa la carpeta `starter-files/` de la lección correspondiente.
